#### 1.2 模块介绍

`ActionDispatcher` 是基于动作字典的命令分发器，把抽象动作描述转为具体鼠标/键盘/截屏操作，是框架的**执行层**。

- **核心方法**：`dispatch(action)`，按 `action["type"]` 调用 `_do_<type>`，新增动作只需加方法。
- **输入**：`{"type": "...", 其他参数...}`
- **输出**：`{"type": "ok"}` / `{"type": "image", "data": ...}` / `{"type": "text", "data": ...}`

**支持 19 种动作**：截图、光标位置、鼠标移动/点击（左中右）/双击/拖拽/按下抬起/滚动、按键（单键/组合键/按下/抬起）、文本输入。
| action type | 输入字段 | 必填字段 | 可选字段 | 输出 |
|---|---|---|---|---|
| `screenshot` | — | — | — | `{"type": "image", "data": <PNG bytes>}` |

| `mouse_move` | `x`, `y` | `x`, `y` | — | `{"type": "ok"}` |

### 2 屏幕元素检测与提取模块

#### 2.1 代码位置

1. `src/screen_element_extractor.py`
2. `src/test_extractor.py`

#### 2.2 模块介绍

`ScreenElementExtractor` 是屏幕截图结构化解析器：输入一张截图，输出带类型、坐标、文本的 UI 元素列表 + 可视化验证图。

- **核心方法**：`process(image_path, ...)` → `(结构化结果字典, 验证图)`
- **流程**：EasyOCR 识别文字 → OpenCV 检测图形 → IoU 去重融合 → 推断类型 → 绘制验证图
- **验证图配色**：🟢 button、🔵 text、🟠 input、🟣 icon

#### 2.3 功能验证

**输入**：`documents/image/screenshot.png`

**结果**：`documents/image/output_annotated.png`, `documents/output_elements.json`

| 类型 | 数量 |
|------|------|
| button | 11 |
| text | 20 |
| input | 6 |
| icon | 44 |

**输出 JSON 片段**：

{
