# ScreenElementExtractor 模块介绍

## 一、模块定位

`ScreenElementExtractor` 是一个**屏幕截图结构化解析器**。它把一张普通的屏幕截图，转换成一份**带类型、带坐标、带文本的 UI 元素列表**，并输出一张**可视化验证图**，方便人眼核对检测结果。

**核心方法**：`process(image_path, output_image_path=None, output_json_path=None)` → 返回 `(结构化结果字典, 可视化验证图)`。

**输入**：屏幕截图路径。

**输出**：一份带类型、坐标、文本的 UI 元素列表，以及一张可视化验证图。


---

## 二、核心能力

| 能力 | 实现方式 | 产出 |
|------|----------|------|
| **文字识别** | EasyOCR | 每个文本块的 bbox、内容、置信度 |
| **非文字元素检测** | OpenCV 自适应阈值 + 形态学闭运算 + 轮廓检测 | 按钮/图标等纯视觉区域的 bbox |
| **结果融合去重** | 基于 IoU（交并比）过滤被 OCR 覆盖的轮廓 | 去重后的统一元素列表 |
| **类型推断** | 依据文本长度、宽高比等启发式规则 | `button` / `text` / `input` / `icon` |
| **可视化验证** | OpenCV 绘制彩色框 + 编号 + 文本标签 | 标注图 PNG |
| **结构化输出** | JSON 序列化 | 元素列表 JSON 文件 |

---

## 三、处理流程（四步流水线）

```
输入截图
   │
   ├─► 步骤1  _run_ocr()          EasyOCR 识别文字，过滤 conf<0.3
   │
   ├─► 步骤2  _run_visual_detect() OpenCV 轮廓检测非文字区域，多重面积/尺寸/长宽比过滤
   │
   ├─► 步骤3  _merge()            以 OCR 为主，轮廓若与已有元素 IoU≥阈值 则丢弃（去重）
   │                              并为每个元素分配 element_id、推断 type
   │
   └─► 步骤4  _draw()             绘制彩色框 + #编号 + 文本，生成验证图
   │
   ▼
输出 UI元素列表(json) + 可视化验证图(png)
```

### 各步骤关键设计

**步骤 1 · OCR**：`EasyOCR.readtext` 返回四点多边形，统一转为 `[x1,y1,x2,y2]`，低置信度（<0.3）过滤。

**步骤 2 · 视觉检测**：多级过滤剔除噪声——
- 面积 `< 200` 或 `> 图面积 50%`
- 宽 `< 10` 或 高 `< 8`
- 长宽比 `>15` 或 `<0.05`（细长条）
- 几乎等于整图的框（全屏边框）

**步骤 3 · 融合策略**：**OCR 优先**。OCR 元素先全部保留，轮廓元素只有在与所有已保留元素 IoU 都 `< iou_threshold`（默认 0.3）时才加入，避免"文字区域被轮廓重复框一次"。

**步骤 4 · 类型推断启发式**：
| 条件 | 推断类型 |
|------|----------|
| 有文本且 `len≤6` 且 `h<50` | `button` |
| 有文本（其他情况） | `text` |
| 无文本且 `30<w<300`、`20<h<60` | `input` |
| 其余 | `icon` |

## 四、输出说明
### 结构化UI元素列表
输出示例:
```json
{
  "screenshot_size": [1920, 1080],
  "element_count": 42,
  "elements": [
    {
      "element_id": 1,
      "bbox": [120, 80, 260, 112],       // [x1, y1, x2, y2]
      "center": [190, 96],                // 中心点，便于后续点击
      "text": "确定",
      "confidence": 0.9821,
      "source": "ocr",                    // ocr | contour
      "type": "button"                    // button | text | input | icon
    }
  ]
}
```
- `source`：标记该元素来自 OCR 还是轮廓检测，便于调试

### 可视化验证图
在原图基础上框选所有检测出的元素，与 UI 元素列表一一对应，不同颜色代表不同的元素类型。

| 元素类型 | 颜色（BGR） | 显示颜色 |
|----------|-------------|----------|
| `button` | `(0, 200, 0)` | 🟢 绿色 |
| `text` | `(200, 150, 0)` | 🔵 蓝色 |
| `input` | `(0, 165, 255)` | 🟠 橙色 |
| `icon` | `(255, 0, 200)` | 🟣 紫红色 |
| 其他/默认 | `(0, 255, 255)` | 🟡 黄色 |
